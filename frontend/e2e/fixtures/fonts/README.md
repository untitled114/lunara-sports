# Inter webfont (captured)

`inter.css` is the stylesheet `index.html` links,
https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap, fetched
with a Chrome 140 Linux user agent on Sep 25, 2026 at 1:44 PM EDT. The `.woff2` files are
the seven files it references on fonts.gstatic.com, stored byte for byte under their URL
path with `/` replaced by `_`. mockApi.js serves both, so screenshots render real Inter
without touching the network. Inter is licensed under the SIL Open Font License 1.1.

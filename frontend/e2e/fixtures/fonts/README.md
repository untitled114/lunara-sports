# Inter webfont (captured)

`inter.css` is the stylesheet `index.html` links,
https://fonts.googleapis.com/css2?family=Inter:ital,wght@0,400;0,500;0,600;0,700;1,900&display=swap,
fetched with a Chrome 140 Linux user agent on Sep 25, 2026 at 4:09 PM EDT (the 900 italic is
for the `.display-wordmark`, ruling D31). The `.woff2` files are the fourteen files it references
on fonts.gstatic.com (seven upright, seven italic), stored byte for byte under their URL path
with `/` replaced by `_`. The seven upright files are unchanged from the 1:44 PM EDT capture.
mockApi.js serves both, so screenshots render real Inter without touching the network. Inter is
licensed under the SIL Open Font License 1.1.
